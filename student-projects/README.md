# Student projects — reference solutions

Plain Vite + React (JavaScript) projects, no Tailwind, no router: the same shape students
get from `npm create vite@latest`. Each runs on its own:

```bash
cd 02-dashboard
npm install
npm run dev
```

| Folder | Lesson | What it is |
|---|---|---|
| `01-react-day1` | 3–4 | First project: Hello React → Header / MainContent / Footer |
| `02-dashboard` | 5 | Dashboard exercise: 5 components, Card used 3× with props |
| `03-rebuild` | 6 | Closed-book rebuild challenge: App, Header, Card ×2, Footer bonus |
| `04-product-list` | 6 | Architecture exercise tree: Navbar / ProductList / ProductCard ×3 / Footer |

Nothing here uses state, events, or `.map`. That is deliberate: Day 1 is components,
JSX, and props only.
